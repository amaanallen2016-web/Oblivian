## 🚀 Getting Started

1. Open `index.html` in a modern web browser
2. Click "Enter OBLIVIAN" to boot the system
3. Unlock the system to access the desktop
4. Use the Start menu or double-click desktop icons to launch apps
5. All features are accessible from the taskbar

# Oblivian

Made by @amaanallen2016-web

This repository is the Oblivian OS rebrand and Linux/Docker scaffold.

Quick start

- Serve locally: `./scripts/serve.sh 8000`
- Docker (recommended): `docker-compose up --build`

Includes:
- Updated static site with Oblivian loader (index.html)
- Dockerfile + docker-compose (Meilisearch scaffold)
- scripts/rebrand.sh, scripts/serve.sh
- diagnostics.html for game testing
- search/ README for Meilisearch examples
